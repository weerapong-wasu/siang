# SIANG · เสียง — Everyone Can Read Thai

Day 1 of the **"1 Day 1 App"** project by Forma Corporation 🇹🇭

Learn the sounds of Thai — all 44 consonants, 32 traditional vowels (สระ ๓๒),
5 tones, survival phrases, and Thai numbers — with audio, visual pitch guides,
and interactive practice.

**Free for everyone. Designed for everyone.**
Built on the belief that knowledge should be accessible to every person,
of every background, every ability — ใครๆ ก็อ่านไทยได้

## Features
- 🔤 44 consonants with class colors, IPA, and tap-to-hear audio
- 🎈 Complete 32-vowel system incl. historic ฦ ฦๅ
- 🎵 5 tones with visual pitch contours + Minimal-Pair Lab
- 🧳 Survival Thai: 26 essential phrases in 5 categories
- 🔢 Thai numbers 0–1000 + "Hear a price" listening quiz
- ♿ WCAG AA: full keyboard nav, screen-reader support, high contrast,
  text scaling, reduced motion, dyslexia-friendly font
- 📱 Fully responsive, single HTML file, zero dependencies
- 🔒 Zero data collection — no accounts, no cookies, no tracking
